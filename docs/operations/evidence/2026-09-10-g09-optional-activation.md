# G09 任意能力の使用・不使用と秘匿

対象は `common:G09#activation/explicit-optional-use` と `common:G09#activation/decline-preserves-secret`。既存の ability-critical fixture の実攻撃から生じる未公開イダの必殺の機会を使用した。fixture の初期配置・人物設定は試験用であり、正式 START からの一戦の証明ではない。

- Engine 2ケース: 明示使用と全PASSを比較。選択肢の閲覧は状態を変更せず、他席による偽装使用を拒否する。不使用は専用判定・使用履歴を作らず4ダメージ、使用は固定出目2/3で8ダメージと使用履歴1件。各遷移でJSON再実行一致、物理札220枚一意、第三者に実キャラID・当該候補がないことを確認。
- Worker 2ケース: 実DO/WebSocketで各操作後に休止し、同一コマンド再送のACK・保存状態・4席のゲーム投影の一致を確認。使用時は実出目から死亡/8/4を判定し、不使用時は4ダメージと履歴不変を確認。
- Browser 2ケース: 所有者の必殺ボタンから使用、またはパス。不使用前/使用判定中の所有者再読込と第三者再読込を行い、秘匿と最終結果を確認。専用履歴がないことの証明はEngine/Workerで行う。
- `pnpm typecheck` 成功。ゲーム本体の変更なし。

初回Worker試験はRoomView全体を比較したため、接続・切断に伴うmembers.connected差分で失敗した。保存状態全体の一致は維持し、投影の比較をgameへ限定した再実行で2件成功。初回にはworkerd異常終了も記録され、成功結果は再実行ログによる。

参照IDとログは同名JSONを参照。G09は複数能力群へ適用する共通条項であり、この2ケースだけで全任意能力や公開必須の境界を証明しない。両行のpending、独立レビュー条件、accepted gateは維持する。
