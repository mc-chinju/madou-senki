# G09 任意ドロー置換

対象はチャム「なになに」と変身後ランスロット「成長」。`drawAbilityOptions` は本人の選択肢を提示し、`transitionTurnPackage` は `CHOOSE_DRAW` に選択されたabilityIdがある場合だけ置換を開始する。通常のドローや引かない選択で能力を自動適用しない。

追加DO試験は2人物×引かない/通常/能力の6ケース。各選択後に休止復帰し、同一コマンドを再送してACK・保存状態が一致する。解決後も同じコマンドを再送し、手札増加が0/1/2、能力使用記録が0/0/1になることを確認。能力不使用では能力frameとused履歴全体も不変。全ケースで物理札220枚一意を確認する。未公開チャムでは他席に実キャラID・ドロー能力候補を送らない。成長は実際のリーア公開→ランスロットの明示変身→各席手番→次のドローを既存fixtureが生成し、変身後の正体は公開されている。

追加Browser2件は能力チェック欄を未選択のまま再読込し通常ドローを実行、1枚増加と再読込後の状態を確認する。チャムは他席の候補・チェック欄・実キャラIDも秘匿。既存の使用/取消4ケースも実行して2枚/1枚を確認した。動的タイトル4ケースは実行証跡として記録し、具体宣言の追加登録には用いない。

Engine既存5ケース（使用2、不使用/不正選択/取消2、実強制公開から変身して成長1）成功。前2群にはdraw phaseを直接設定する試験用状態が含まれる。これらを正式STARTの証明とはしない。DO6・Browser6・全型検査成功。本体変更なし。参照IDとログは同名JSON。

G09の情報能力・ライフサイクル任意入口と候補受け入れは未完、pending維持。次はこれらの入口について既存宣言を対応付け、不使用時の処理再開と公開範囲の不足を埋める。
