# R4 名称列挙の従者7種の実死亡回収

`reuse-abilities.test.ts` に、歌う船・飛竜・グリフォン・スケルトン・ゾンビー・ワイト・デス・ナイトの7ケースを追加した。本人が実配置し、次のシンの実手番に妖撃破山剣で攻撃する。飛竜は従者Lv6のため、必勝の祈りを実使用して攻撃効果を上げる。従者死亡を直接注入せず、実際のfollower-diedを確認する。

無制限回収を選び、能力宣言から予約成立までJSON保存復帰する。予約中は手札にも捨て札にもなく、親終了後に一枚だけ手札へ戻る。従者配置へ戻らず、通常枠も消費しない。
