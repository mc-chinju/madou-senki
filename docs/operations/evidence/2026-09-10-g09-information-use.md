# G09 情報能力の明示使用対応

既存の明示USE_ABILITY試験を共通条項 `activation/explicit-optional-use` へ対応付けた。前回の9種不使用マトリクスと合わせて、閲覧・捨て札・交換・秘匿化・強制公開の効果を本人が選ぶことを示す。

Engine9件はチャム、リーア、レスター、アルセイル占星/影、ランカスター、双子2人物、ウーノスの9能力。実コマンドの前提となる人物/従者/距離/相手公開などには試験用配置が含まれる。すべての前提を正式STARTから作ったという証明ではない。

Worker3件は実DO/WebSocketを使用したリーア/アルセイルのprivate-inspection保存と捨て札一回確定、アイエルの手札交換一回確定。部屋試験ファイル内のEngine直接呼び出しをDO証拠として数えない。Browser3件はランカスターの魔法技捨て札、アルセイルの影、ウーノスの強制公開の明示操作。

参照IDと実行ログは同名JSON。今回の変更は台帳と文書のみ。型に影響するコード変更がなく、型検査は再実行していない。実装/テストコードは前回の型成功から変更していない。

G09の残りは `availableLifecycleAbilities` が返す3種（lancelot-transform、vanmil-subordinates、arseil-conspiracy）の共通条項対応。各能力全条項の受け入れや独立レビューをこの対応で置き換えない。pendingと候補gateを維持する。
