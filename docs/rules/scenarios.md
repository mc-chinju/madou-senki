# 受け入れシナリオ

2nd Editionの裁定から作成した[32件の仕様例 S01–S32](second-edition/scenarios.md)と、対応する[機械可読データ](../../data/second-edition/scenarios.json)を正本とします。

各例を実際のエンジン入力・固定乱数・期待状態へ対応付けて検証します。通信順序や再送の例はDurable Objectの境界でも確認します。既存テストの総数だけを根拠に、32件すべてを実行済みとは扱いません。

現在の合格範囲と残作業は[実装進捗](../implementation-progress.md)、カード効果ごとの実行可能な検証範囲は[実装カバレッジ](coverage.md)を参照してください。
