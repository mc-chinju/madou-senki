# 第2版 キャラクター全26枚の仕様

全7ページを目視照合。表記揺れは原資料の名称を残す。能力の原文条件を操作可能な文に整理した仕様案で、オンライン裁定は [裁定仕様](rulings.md) を併読する。

初期配布24枚: GOOD11 / EVIL13。変身専用2枚。精神力は3rdの「潜在力」と混在させない。

## c2-p01-r1c1 白魔術師シェリム（男）

出典: [Character(A4).pdf p.1](../../../resources/original/second-edition/Character(A4).pdf#page=1)、1行1列。

戦士Lv 0 / 魔法Lv 8 / 精神力 8 / 耐久力 12。陣営: GOOD。目的: EVILの全滅。敗北条件: リーア姫の死亡。

持ち技: 白輪、白光、裂界、天舞。持ち従者: 天使。

制限: なし。白の護り手：常にGOOD

- **絶対結界**（defense）: 効果Lv5以下の攻撃をすべて無効にする。また、従者で受ける前の技のダメージが5点以下の技（ダメージそのものがない技も含む）をすべて無効にする。
- **賢者の杖**（attack-modifiers）: すべての魔法技の効果Lv+1。
- **大魔術師**（use-validation）: 魔法技は詠唱不要。
- **強化詠唱**（attack-declaration）: キャラクターカードを表にしていれば、詠唱状態にした魔法技を任意の者全てに与えられる。

## c2-p01-r1c2 大神官ジル（男）

出典: [Character(A4).pdf p.1](../../../resources/original/second-edition/Character(A4).pdf#page=1)、1行2列。

戦士Lv 6 / 魔法Lv 5 / 精神力 7 / 耐久力 18。陣営: GOOD。目的: EVILの全滅。敗北条件: リーア姫の死亡。

持ち技: 殴る、蹴る、気破、死鬼界滅拳、死鬼滅殺拳、死鬼旋風脚、神罰、封傷。持ち従者: 女神官シャイア。

制限: なし。

- **気闘術の奥義**（counter-declaration）: 精神力チェックに成功すれば、格闘技を反撃技に変えられる。
- **鉄拳**（attack-modifiers）: 格闘技の効果Lvを自分の戦士Lvまで上げることができ、ダメージ+1d6。
- **拳圧**（attack-declaration）: 近距離の格闘技を遠距離技にできる。
- **信仰心**（check-resolution）: ディア、ガドューラ、レスターの精神力-1チェックを行う「恐怖」「魅了」「魔詩」の特殊能力に対して、ゾロ目の効果を受けない。

裁定・照合項目:
- 従者欄は「女神官シャイア」。行動カードの「女神官のシャリア」との対応を別名台帳で決める。

## c2-p01-r2c1 侍大将のシン（男）

持ち技: 天地百撃斬、天地爆砕剣。持ち従者: なし。

- **居合抜き**（use-validation）: 剣技なら精神力チェックに成功すれば、詠唱せずに使用可能。

## c2-p01-r2c2 小妖精のチャム（女）

戦士Lv 0 / 魔法Lv 3 / 精神力 8 / 耐久力 7。陣営: GOOD。目的: EVILの全滅。敗北条件: リーア姫の死亡。

持ち技: なし。持ち従者: なし。

制限: 自身が与える戦士技のダメージ半減。

- **ぶーんぶーん**（distance-response）: 「間合い」カードを1枚出すと、敵は「踏み込み」カードを2枚出さないと無効にできない。
- **なになに**（draw）: 自分の手番の時、手札を1枚でなく2枚補充できる。
- **見ちゃった**（own-turn-extra）: 自分の手番の時、手番と別に一人だけ任意のキャラクターの従者を全て見られる。
- **いたずらしちゃった**（ability-response）: 自身のキャラクターカードを表にしているとき、キャラクターカードを表にしたディア、ガドューラ、レスターの「魅了」「恐怖」「魔詩」の特殊能力を使えなくする。
- **みんな姫様を頼むね**（death-before-discard）: 死亡したとき、任意のキャラクターに手札を1枚だけ手渡せる。

## c2-p03-r2c1 吟遊詩人のレスター（男）

出典: [Character(A4).pdf p.3](../../../resources/original/second-edition/Character(A4).pdf#page=3)、2行1列。

戦士Lv 4 / 魔法Lv 5 / 精神力 8 / 耐久力 13。陣営: GOOD。目的: EVILの全滅。敗北条件: リーア姫の死亡。

持ち技: 魔詩、呪歌、死詩、勇気、ソロモン王の護符。持ち従者: なし。

制限: なし。

- **魔詩**（attack-received）: 反撃されたときを除き、敵から攻撃を受けたとき、敵に精神力-1チェックを要求できる。失敗するとレスター自身への攻撃のみが失敗する。このチェックがゾロ目なら無条件で攻撃失敗、攻撃者は次の自分の手番まで停止。6のゾロ目なら攻撃者はレスターと同じ陣営になり、目的が「EVILの全滅」、敗北条件が「リーア姫の死亡」になる。
- **幻術**（attack-modifiers）: 自分の魔法Lv以下の技を全て精神技にでき、人の従者を無効にできる。キャラクターカードが表になったアーネスの「女性親衛隊」の特殊能力を無効にする。
- **噂**（own-turn-extra）: 自分の手番と別に精神力-3チェックに成功すると、裏になったキャラクターカードを自分だけ見られる。
- **月の愛**（reclaim）: キャラクターカードを表にしていれば、「月の竪琴」「魔詩」「呪歌」カードを常時再使用可能。

裁定・照合項目:
- 持ち技欄「死詩」と行動カード「死歌」の対応を別名台帳で確認。
- 6のゾロ目で陣営が変わった場合も停止を併発するかを共通裁定。

## c2-p04-r2c1 占星術師のアルセイル（男）
