## データの意味

[data/second-edition](../../../data/second-edition) のJSONは構造化された仕様カタログ。各行動カードに出典位置、印刷本文、使用タイミング、処理仕様、疑問、目視照合フラグを保持する。人物は基礎値、陣営、目的、持ち技/従者、110能力を保持する。OCRだけで採用せず、行動25ページ・人物7ページを画像で照合した。人物は別担当が全26枚を再照合した。

`specification`は日本語の正規化記述であり、実行可能な効果DSLではない。実装では型付き効果と専用ハンドラーへ変換する。`visually_verified`は原資料との照合を表し、ゲーム動作の検証を表さない。原文の疑問は裁定案ができても削除せず、案と出典を分けて追跡する。

印刷デッキ構成は技97、踏み込み21、間合い15、従者40、OPEN5、一般42で合計220。JSONの`category`は使用上の区分も含むため、そのまま印刷区分と比較しない。間合い/休息や踏み込み/武器は1物理札に複数用途がある。

## 試作・実戦で重点確認する6項目

| 論点 | 今回の推奨案 | 影響 |
|---|---|---|
| 同じ能力・必勝の祈りの再使用 | 同じ元イベントに同じ物理札/能力は1回 | 無限強化・無限再判定を防ぐ。原文にない回数補完 |
| 山札切れ | 捨て札をシャッフルして補充継続 | 自動再編の明記がないため紙の卓の運用を確認 |
| 持ち技の回収 | 基本の1回は人物×名称単位。蘇生・複製でリセットしない | 「一回」が名称/物理札どちらを指すか曖昧 |
| 祈願 | 山札検索可。通常札は手札、OPENは公開領域。既公開OPENの一回効果は再発動しない | 「どこからでも」の範囲と取得後状態を補う |
| 光王陣・獣王剣 | 明示例外として対象・構成札・条件・使用順を個別定義 | 単純な通常反撃やダメージ加算では表せない |
| 同時死亡・復活 | 同時結果と誘発を完了して勝敗確定。将来の復活ドローは待たない | 処理する席順で勝者が変わるのを防ぐ |

「聖光」の欠けた主語や「死詩/死歌」「水晶球」などの表記にも仮対応を置いた。作者による正誤表ではない。普段の対戦で使う裁定があれば、該当箇所を次の裁定版で変更する。
