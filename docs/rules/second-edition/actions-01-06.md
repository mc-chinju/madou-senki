# 第2版アクションカード仕様：原本1～6ページ

原本は [CardAll.pdf](../../../resources/original/second-edition/CardAll.pdf)。各ページの3×3配置を上から左→右の順に記録した。物理カード54枚、空白セル0枚。重複カードも別IDを与える。

本文は画像から転記し、空白・改行・半角カナを正規化した。仕様は印刷条件を操作へ分解したもので、確認事項に挙げた点は未確定。第3版の記述は混ぜていない。複合・防御は管理上 `technique` に分類し、印刷カテゴリと複数用途を別途保持した。

## a2-p01-r1c1：そうかっ！あれが伏線だったのか

出典：[原本1ページ](../../../resources/original/second-edition/CardAll.pdf#page=1)、1行1列。印刷カテゴリ：OPEN。目視確認済み。

**印刷本文**

> 死亡したキャラクターが、死んだときの陣営でゲームに復活するかもしれない。死亡したキャラクター毎に1d6を振り、1～4を出すと生き返ったことに出来る

**使用・解決タイミング**

- OPENカード公開時（公開の一般手順は基本ルール参照）

**処理仕様**

- 死亡しているキャラクター全員について、それぞれ1d6を振る。
- 出目1～4なら、そのキャラクターを死亡時の陣営で復活させることができる。
- 出目5～6のキャラクターはこの効果では復活しない。

**確認事項**

- 「出来る」の選択者は誰か。
- 復活時の耐久力・手札・従者・設置カード・目標および敗北条件の扱いは本文にない。
- 死亡でゲーム終了条件が成立した場合、このOPENを処理する余地があるか。

- 身代わりをさらに身代わりする連鎖が可能か。
- 対象変更後の距離・技の対象条件の再確認要否は本文にない。

## a2-p02-r2c3：命運凶変

- 特殊能力の使用回数を消費するか。
- このカード同士の割込と、神性介入による振り直しの順序は本文にない。
- OPENの強制公開が「使用しようとした手札」に含まれるか。
