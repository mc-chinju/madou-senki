# 第2版 p.18–25 カード別オンライン裁定案

**全項目「オンライン補完・暫定採用」。公式裁定ではありません。** 原典の曖昧さをオンラインで一意に処理するための推奨案です。暫定採用後も原文に曖昧さがある事実を残すため、原典仕様の `questions` は保持します。

原典と質問: [カード仕様](actions-18-25.md)、[機械可読仕様](../../../data/second-edition/actions-18-25.json)、[CardAll.pdf](../../../resources/original/second-edition/CardAll.pdf)。共通の割り込み・距離・死亡・乱数処理は [共通裁定仕様](rulings.md) を参照します。F01–F67は印刷された物理カードの順で1枚に1ID、F68はキャラクター能力による仮想従者です。同名カードも別IDを持ちます。

## 全裁定で共有する処理

- **個別文の例外を優先する。** 「全員」と「任意の者全て」、従者の士気免除と技の使用チェック免除、空と飛、魔と戦を同一視しない。特殊能力の使用は制限以外は任意で、自動的な最大効果の選択はしない。
- **通常防御はヒット別、従者受けは同時集合。** 各対象について残存する全ヒットの通常手札・能力防御を終えてから従者防御を開始する。開始時の従者配置を同時集合のスナップショットとして保持し、その対象は通常防御に戻れない。第三者の明示的な介入は共通の受付窓に従う。
- **複数ヒットでも士気は各従者につきグループ1回。** 技Lvが従者Lvより高い複数のヒットを同じ従者が受ける場合、全ヒットそれぞれからHPを軽減する。1発目で札を先に取り除いて2発目以降の軽減を消さない。各ヒットのLv比較・固有効果を計算し、最後に破壊・捨て札をまとめて確定する。別攻撃グループはその後の配置状態を参照する。この同時受けはMadoRule.pdf p.5の複数個技の規定を土台にし、スナップショットと士気の共有単位はオンライン案として明示する。
- **数値は固定値→加算→倍化→最後に切捨て。** 同じ攻撃の発数・攻撃値の乱数は全対象で共有し、別に記載された乱数式は別々に振る。抵抗判定は対象別、士気は対象内の従者別。確定済みの攻撃値を途中で振り直さない。
- **反射は1ヒットずつ処理する。** 元の宛先へのヒットを消して直前の攻撃元へ返し、新たな宛先は再防御できる。反射源は同一ヒット系譜に1回だけ。王立騎士団の反射は反撃技を使う行為ではなく、「反撃技使用不可」の対象外。
- **支払済みコストは返さない。** 同じ物理札または同じ能力の同じイベントへの試行は1回まで。失敗後に別の有効な防御を試せることと、同じものを繰り返し試せることは区別する。

### 「全員」と任意対象の範囲（2026-09-08・補足）

攻撃欄に単独で記された「全員」は、宣言時に攻撃できる自分以外の人物すべてを対象とする。死亡・流浪・異界・退場など対象にできない人物と、正体を公開した同陣営の人物は除く。未公開人物の秘密の陣営を根拠に対象を除外しない。有効な対象が0人なら使用できない。「任意の者全て」は、有効な対象から1人以上を選ぶ。T42の「全員に使用可能」は同裁定どおり人数上限の拡張であり、この単独表記とは区別する。

対象集合は宣言時に固定する。その後不在になった対象への効果は終えるが、新しい対象を追加したり別人へ振り替えたりしない。対象が1人に固定された追加攻撃の機会では、「全員」の合法対象集合がその1人だけの場合に限り使用できる。原文の対象制限と全員・任意の区別をオンライン操作へ落とすための暫定補足であり、公式裁定ではない。

## カード別の質問と推奨回答

<a id="f01"></a>
### F01 — a2-p18-r1c1 沈黙

状態: **オンライン補完・暫定採用**。 [原典p.18](../../../resources/original/second-edition/CardAll.pdf#page=18)。

**質問1:** 「-2/-1」は初回-2・以後-1か、持続効果の共通回復規則と照合する。

**推奨裁定:** 最初の精神力-2チェックは沈黙の命中時に行う。成功なら沈黙を付与せず、失敗したら魔法使用禁止を付与する。次の対象自身の手番の回復段階からは精神力-1で、成功するまで毎回判定する。これはMadoRule.pdf p.4の修正列を命中時から使う規則と共通G17に従う。新たな沈黙は別の持続効果として管理し、一つの成功で他の沈黙も解除しない。

**質問2:** 魔法禁止の範囲に、魔法防御・魔法反撃・詠唱・魔法として使う従者・特殊能力のどれが含まれるか。

**推奨裁定:** 沈黙中は魔属性の技の攻撃・防御・反撃・新規詠唱・詠唱からの発動を禁止する。従者を魔属性の攻撃技に転用することも禁止する。既存の詠唱札は保持し、解除後に使用できる。魔法技を出したことにする氷刃などの能力も禁止するが、魔法Lv補正・魔法抵抗・従者の受動防御など、魔法技の使用そのものではない能力まで一律には禁止しない。

### F02 — a2-p18-r1c2 紋竜破

状態: **オンライン補完・暫定採用**。 [原典p.18](../../../resources/original/second-edition/CardAll.pdf#page=18)。

**質問1:** 反撃技禁止と王立騎士団の自動跳ね返しの相互作用。

**推奨裁定:** 反撃技の使用禁止は反撃カードや技を反撃技として使う行為に適用する。従者自身の跳ね返しは反撃技の使用ではないため禁止されない。王立騎士団の士気・効果Lv4以下という条件は別に満たす必要があり、通常の紋竜破（効果Lv6）は反射対象外。防御補正等で4以下になった場合にだけ反射可能となる。

### F03 — a2-p18-r1c3 地裂

**質問2:** 同時対象の宣言・防御順と共通の踏み込みの扱いは複数対象共通裁定による。

**推奨裁定:** 宣言時に対象集合を固定し、攻撃値は全対象で共有する。対象ごとの通常防御がすべて終わった後、対象ごとの従者防御へ進む。対象の入力受付順、距離と踏み込みの共通処理は裁定仕様の対称・非推移なペア距離と複数対象手順を用いる。途中結果を見て対象を入れ替えない。

### F04 — a2-p18-r2c1 石化

状態: **オンライン補完・暫定採用**。 [原典p.18](../../../resources/original/second-edition/CardAll.pdf#page=18)。

**質問1:** 石化判定とダメージ・死亡時効果の解決順。

**推奨裁定:** 本人まで届いたヒットについて、命中誘発の受付後、ダメージを適用する前に石化の精神力チェックを1回行う。成功なら石化せず、失敗なら石化による即死を適用予定として保持する。その後、ダメージ5の各種補正後の値と即死結果を共通G15の同時確定段階でまとめて適用する。ダメージを先行適用して死亡処理を始めず、ダメージ死と石化死が重なっても一つの死亡イベントとする。無効化・回避・従者で停止された場合は石化判定をしない。死亡時能力・身代わり・復活等の受付は共通の死亡処理に従う。

**質問2:** 石化死亡が通常の復活で回復可能か、個別の復活制限との照合が必要。

**推奨裁定:** 石化を死亡原因として記録するが、このカードには蘇生禁止がないため通常の復活対象にできる。復活時には石化状態も除去する。別の効果が復活禁止を明記している場合はその制限を優先する。

### F13 — a2-p19-r2c1 スケルトン

状態: **オンライン補完・暫定採用**。 [原典p.19](../../../resources/original/second-edition/CardAll.pdf#page=19)。

**質問1:** 復活は印字の効果Lvちょうどの場合か、その値以下を含むか。復活する時点、配置位置、HP軽減・後続従者への通過との順序を確定する。

**推奨裁定:** 復活の印字Lvを上限と解釈し、その値以下の技に通常の従者比較で破られた場合に適用する。自身の従者Lvより低い技はそもそも防ぎ、同値の技は止めて通常は死亡するが復活対象となる。技Lvが従者Lvより高ければ各ヒットから印字HPを軽減して後続へ通し、そのグループの処理後に同じ配置位置へ復帰する。復帰した札を同じグループに再投入しない。士気失敗、直接の除去・捨て札化、破壊効果を持つ技による破壊では復活しない。上限を超える技・復活禁止となる破壊が同じ同時グループに一つでも含まれて破壊した場合、グループ全体で復活不可とする。各ヒットは防御開始時の同じ従者状態を参照するため、先のヒットで破壊予定になっても残り全ヒットのHP軽減を失わない。

### F68 — キャラクター能力の仮想従者と物理従者

状態: **オンライン補完・暫定採用**。対象: `c2-p03-r2c2` アーネス「女性親衛隊」、`a2-p21-r2c2` 女性親衛隊、これを無効にするレスター「幻術」およびヴァンミールの能力。

- アーネスの能力が有効で本人が使うことを選んだ攻撃グループに、物理カード枠と別の仮想従者を前衛へ1体生成する。属性は人・女、従者Lv4、HP1、従者無視の効果を無視する。物理カードの女性親衛隊（Lv5・HP4・士気あり）から数値や士気をコピーしない。
- 仮想従者も同じ残存ヒット集合に含める。全ヒットでそれぞれLv比較し、Lv超過ヒットのすべてからHP1を軽減する。先のヒットで破壊予定になっても、同じ同時集合の後続軽減を取り消さない。
- 同時集合内の後続ヒットも同じ1体のスナップショットで受ける。集合の解決で破壊された仮想従者を同じグループ内に再生成しない。未破壊であっても、その攻撃グループの後処理で仮想従者を消す。共通G02により別グループとなる追加攻撃・反撃では、能力が有効であれば新たな1体を生成できる。
- 能力を無効にされた時点がスナップショット作成前なら生成しない。作成後の無効化では、すでに固定した同時集合を遡って変更せず、以後に生成する別集合・別グループへ反映する。レスターの幻術による仮想従者能力の無効化は物理カードの女性親衛隊そのものを直接消去しない。技の精神化・人従者無効の別条項は独立に適用する。
- 仮想従者は物理札ではないため、手札に奪う・交換する・捨て札から回収する・全軍突撃で札として消費する対象にしない。強制破壊等で消費される時も、実在しない捨て札を生成しない。
- 仮想従者の無視無効化も対象本人の従者列全体を保護する。一般の従者無視は防ぐが、仮想従者の元能力そのものを無効にする明記を防がない。

## 採用前の確認例

以下も公式の例示ではなく、本提案が意図する結果を確認する例です。

1. **スケルトンで同時2ヒットを受ける。** 従者Lv3・HP4が効果Lv4・ダメージ8の技を2ヒット受けると、両方が後続へ通り、各ヒットの残りダメージは4。全ヒット解決後にスケルトンは元位置へ復活する。Lv5の破壊が一つでもあれば復活しない。
2. **グリフォンの士気。** 同じ2ヒット攻撃グループに対し士気は1回。成功して両ヒットにLvで破られたら双方からHP3を軽減する。失敗なら双方とも軽減0で、グリフォンは捨て札となる。
3. **紋竜破と王立騎士団。** 効果Lv6のままなら反射条件を満たさない。効果Lv4まで低下したヒットなら、士気に成功した王立騎士団は反撃禁止に妨げられず反射する。別対象の紋竜破ヒットを同時に消さない。
4. **ゴーレムに精神技。** 通常の精神技はゴーレムを残して通過し、HP軽減0。精神技に別途「空以外の従者破壊」がつけば、地・石のゴーレムはその明示破壊を免れない。
5. **後衛の守護者に従者無視。** 無視を受ける入口で守護者を公開して士気を判定。成功ならその対象への無視を打ち消し、前衛から通常防御する。失敗なら列への無視が続く。他プレイヤーへの無視はどちらの場合も変わらない。
6. **妖精族の乱数。** Lv用出目2・ダメージ用出目5なら基本攻撃Lv5・ダメージ9。その攻撃の全対象は同じ5・9を受け、各自の防御・抵抗で別に結果が変わる。
7. **水竜で停止。** Aが水竜を使いBへ命中させた場合、B自身の手番が先に来ても水竜の停止は続き、次のAの手番開始で解除する。Aがその前に死亡していても、次にAの席順が来た時に解除する。
8. **仮想従者と同時3ヒット。** アーネスの仮想従者がLv5・ダメージ6の3ヒットを受けるなら、各ヒットはHP1軽減で5となる。最初のヒットだけ軽減して残りを6とする処理にはしない。集合の解決で消費し、別の攻撃グループで初めて再生成できる。
