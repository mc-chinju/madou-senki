# 2nd Edition 行動カード7–17ページ：個別裁定案

**状態：オンライン補完・暫定採用。公式裁定ではない。** 「原文で確定」はローカルの2nd Editionカードまたはルール本文にある記述、「オンライン補完・暫定採用」はオンラインで一意に解決するための推奨処理を示す。元カタログの曖昧さは消していない。

出典：[カード仕様](actions-07-17.md)、[CardAll.pdf](../../../resources/original/second-edition/CardAll.pdf)、[MadoRule.pdf](../../../resources/original/second-edition/MadoRule.pdf#page=4)、[キャラクター仕様](characters.md)。57件のquestionsを49裁定へ対応付ける。同文の間合い／休息8枚と封傷2枚は同じ裁定を共有する。Q番号は各カードのquestions配列の1始まり番号。

## 共通の前提（すべてオンライン補完・暫定採用）

- 介入は席順の優先権に従い、まだ確定していないイベントだけを対象にする。支払済みコストは失敗・取消でも返さない。違法宣言を入力段階で拒否した場合には支払わない。
- 同じ能力・同じ物理札の同一イベントへの試行は1回。多段の別ヒットは別イベントとするが、魔詩・魅了・恐怖の3能力の判定は同じ攻撃グループの対象ごとに1回。印刷文が2回等を明示すれば個別の例外として扱う。
- 専用文は明示された変更だけが通常の制約を上書きする。「チェック不要」だけでは詠唱を省略しない。反撃禁止は反属性の札の使用自体を禁止し、反属性でない防御や従者の自動効果とは区別する。
- 反射札1枚は1ヒットを扱う。「全て」は反射可能な技種別全てと読む。同一反射源は同一ヒット系譜で1回まで。
- ダメージ計算は固定値を決定→加算→倍化→切捨て。ダメージなしを0へ変換して加算対象にしない。攻撃側の多段・全体攻撃乱数はグループで1回共有し、対象の抵抗は対象ごとに行う。
- 各対象について全ヒットへの通常防御が完了してから、その対象の従者による最終防御を開始する。開始時の従者集合をその対象の各同時ヒットへ適用し、HPを各発から軽減して、従者の破壊は同時集合の計算後に確定する。その対象の通常防御へは戻らない（G14）。
- 命中後を指定する効果は通常ダメージ前の専用窓で処理する。適用前の未確定イベントには第三者の合法な介入を認めるが、死亡予定に入った後は通常の回復で死亡を取り消せない。死亡予定窓はG15の明示された死亡時効果だけを扱う。同時集合のダメージ・即死・自傷をまとめて適用し、蘇生・流浪解除を含む判定後処理が全て終わるまで勝敗を確定しない。

[共通G01–G18](rulings.md)と[キャラクターC01–C13](rulings-characters.md)を読み合わせた版。以下ではこの共通前提を繰り返さず、カードごとの差分を決める。光の加護など、上記3能力以外の精神力を使う防御を一律グループ1回にはしない。

### T01 — 間合い／休息 / Q1

**対応**：`a2-p07-r1c1` Q1、`a2-p07-r1c2` Q1、`a2-p07-r1c3` Q1、`a2-p07-r2c1` Q1、`a2-p07-r2c2` Q1、`a2-p07-r2c3` Q1、`a2-p07-r3c1` Q1、`a2-p07-r3c2` Q1

**元の疑問**：休息による回復の上限と、最大耐久力を変更する効果が併存する場合の上限は、共通回復裁定で定める。

**原文で確定**：印刷は自身の耐久力を1点回復し、複数枚を同時使用可能。最大値を超える回復の許可はない。 [CardAll 7ページ](../../../resources/original/second-edition/CardAll.pdf#page=7)。

**オンライン補完・暫定採用**：回復上限は解決時に有効な最大耐久力とする。n枚の休息を一括使用した場合は蓄積ダメージをmax(蓄積ダメージ−n,0)へ減らし、現在耐久力＝現在最大耐久力−蓄積ダメージとして計算する。上限を変える能力が解決前に有効/無効になったら、その最新の上限を使う。最大耐久力が変わる場合はG08どおり蓄積ダメージを保存して現在耐久力を再計算し、0以下なら死亡予定へ進む。支払った休息札は上限超過分があっても返さない。

### T02 — 黒翼天翔剣 / Q1

**対応**：`a2-p08-r1c2` Q1

**元の疑問**：命中後の踏み込み加算の締切はダメージ適用前か。相手が回復・ダメージ軽減等を挟めるか。複数対象化・多段化した場合に加算をどの対象・発に適用するか。

**原文で確定**：アーネス専用には「命中した後」に踏み込み1枚を捨てるごとにダメージ+5とある。通常ルールのダメージ計算は防御前。 [CardAll 8ページ](../../../resources/original/second-edition/CardAll.pdf#page=8)。

**オンライン補完・暫定採用**：従者処理を経て命中が確定した後、通常ダメージ適用前に専用の加算窓を1回開く。アーネスはk枚を一括で示して捨てる。命中後加算は通常の事前確定に対する明示例外で、固定値→既存加算と5k→倍化→切捨ての順で未適用ダメージを再計算する。技が複数対象/多段になっていれば、一度払った5kは同じ技グループのまだダメージ未確定の命中全てへ共有する。命中しなかった発へ効果はない。加算宣言後、席順で回復・軽減など当該未確定ダメージへ合法な介入を認める。解決済みダメージへの遡及加算や踏み込み支払のやり直しはしない。

### T03 — 手裏剣 / Q1

**対応**：`a2-p08-r2c3` Q1

**元の疑問**：命中後の詠唱全廃棄は命中時に一括宣言するか。詠唱済みカードを「詠唱中」として全て対象にするか。

**原文で確定**：イダ専用は命中すれば詠唱中の技を全て捨てさせることが出来る。MadoRule §7は詠唱して場にある札を後で手札のように使えるとする。 [CardAll 8ページ](../../../resources/original/second-edition/CardAll.pdf#page=8)。

**オンライン補完・暫定採用**：対象ごとの命中時窓で全廃棄の使用/不使用を1回宣言する。対象の詠唱領域にある未消費の全カードを「詠唱中」に含め、詠唱済みでも対象とする。部分選択は不可。廃棄イベント確定前は第三者の合法な介入を認め、解決時にまだ詠唱領域にある札を全て捨てる。既に使用して解決中の技はその領域を離れているので廃棄対象にならない。

### T04 — 裏天空剣 / Q1

**対応**：`a2-p08-r3c1` Q1

**元の疑問**：必殺2回の判定・耐久力消費・通常ダメージの順序と、1回目で死亡した場合の2回目の省略を定める必要がある。

**原文で確定**：イダ専用は命中すれば「必殺」を2回行なえる。キャラクターの必殺は2d6ゾロ目で即死、連続出目でダメージ倍。耐久力を消費する記載はない。 [CardAll 8ページ](../../../resources/original/second-edition/CardAll.pdf#page=8)。

**オンライン補完・暫定採用**：1回の命中に対する必殺判定は通常の1回を含めて最大2回とし、3回にはしない。耐久力コストは0。各回を任意に順次宣言・判定し、2回とも連続出目なら倍化を2回適用して通常ダメージを4倍にする。即死の結果が出たら、その命中へ即死予定を記録し、任意の2回目を省略できる。まだ結果未適用の窓で合法な介入を認めるが、ここで対象の死亡を個別に先行確定しない。2回目を行う場合も同じ命中窓で行う。通常ダメージは必殺窓終了後に値を保存し、G15に従って他の同時ダメージ・即死・自傷とまとめて適用する。死亡予定に入った後は通常の回復による取消を認めず、死亡時効果と廃棄を共通順序で処理する。

### T05 — 影分身 / Q1

**対応**：`a2-p08-r3c2` Q1

**元の疑問**：敵の攻撃を失敗させる本文と通常の反属性によるLv比較の関係はどうか。イダが得る「反撃」は別の反属性カードを出す機会か、反属性のない攻撃技も使える特別な反撃か。

**原文で確定**：本文は相手の技Lvに関係なく使用可能、敵の抵抗失敗で攻撃失敗。イダ専用ではシン以外の敵の攻撃は必ず失敗となり、反撃を行なえる。 [CardAll 8ページ](../../../resources/original/second-edition/CardAll.pdf#page=8)。

**オンライン補完・暫定採用**：固有の攻撃失敗処理に通常反撃の効果Lv比較を重ねない。イダ専用の「反撃」は、失敗させた攻撃の使用者へ直ちに新しい攻撃を1回宣言できる特別な機会とする。反属性の有無は問わないが、攻撃可能な距離、使用条件、使用チェック、詠唱済み要件は通常どおり。影分身自身はダメージなしであり、別の使用可能な攻撃札/攻撃手段が必要。C09どおり新しい進撃・撤退の機会は与えない。シンに対しては失敗化も追加攻撃も得ない。元技が反撃不可なら、反属性を持つ影分身カード自体を出せない。

### T06 — 気斬 / Q1

**対応**：`a2-p08-r3c3` Q1

**元の疑問**：基礎ダメージ欄の「精神力」は術者の精神力を指すと読めるが、対象の値との明記はない。値の固定時機を共通裁定に置く。

**原文で確定**：印刷ダメージは精神力、イダ専用は精神力×2。値の所有者を明記しない。 [CardAll 8ページ](../../../resources/original/second-edition/CardAll.pdf#page=8)。

**オンライン補完・暫定採用**：精神力は術者の有効な現在精神力を指す。通常の防御前ダメージ計算窓の終了時に参照値を固定し、以後術者/対象の精神力が変わってもこの発動のダメージ式を引き直さない。専用効果は同じ固定値を2倍する。

### T07 — 獣王剣 / Q1

**対応**：`a2-p09-r1c1` Q1

**元の疑問**：組み合わせ元の専用効果・詠唱・反撃・近距離属性・GOOD使用禁止等の制限の継承範囲と、合成カードの追加使用チェック/詠唱要否を定める。

**原文で確定**：ウパニシャットは自分の戦士Lv以下の戦士技1枚と組み合わせ、そのダメージ・効果・属性を加えてよい。合成元の使用Lv/効果Lvを足すとは書かれていない。 [CardAll 9ページ](../../../resources/original/second-edition/CardAll.pdf#page=9)。

**オンライン補完・暫定採用**：合成を使うかと合成元1枚を獣王剣の宣言時に固定し、両方を提示して支払う。合成元の印刷使用Lvが現在の戦士Lv以下であることを要求し、その不足を精神力チェックで埋める合成は不可。使う専用効果は術者が適格なものだけで、他キャラクター専用効果は取り込めない。合成元の属性・効果と、それらに付随する使用禁止/対象制限は継承する。GOOD不可等に抵触すれば宣言自体が不合法。近を含むなら近距離制限を優先し、反属性は合成技に付加する。詠唱が必要な合成元は事前に詠唱済みでなければ組み合わせられず、獣王剣の使用チェック不要は詠唱を免除しない。合成元の追加使用チェックは行わないが、本文で別に要求する事前精神力チェックは行う。合成技の使用/基礎効果Lvは獣王剣の6で、合成元のLvを加算しない。

### T08 — 獣王剣 / Q2

**対応**：`a2-p09-r1c1` Q2

**元の疑問**：組み合わせ元の通常ダメージが「−」や可変式の場合の合算、対象数・従者破壊・反射・多段効果の競合、両カードの回収/取消時の扱いが未記載。

**原文で確定**：合成対象は1枚で、そのダメージ・効果・属性を獣王剣に加える。個別カードの「−」はダメージなしを表す。 [CardAll 9ページ](../../../resources/original/second-edition/CardAll.pdf#page=9)。

**オンライン補完・暫定採用**：合成元に数値ダメージがあれば、その印刷値/式による成分を通常計算窓で評価して獣王剣の印刷値10と合計し、合成技の固定ダメージ成分を作る。その後にG08の明示置換→加減算→倍率→最後の切捨てを合成技全体へ一度適用し、同じ術者能力を各構成札へ重複計上しない。合成元がダメージなしなら、その成分を補正可能な数値0へ変えず、獣王剣の数値成分だけを残す。合成元のダメージなし成分には加算でダメージを発生させない。攻撃乱数はグループで1回共有し、対象の抵抗は個別。対象数の明示拡張と多段数は継承し、各発に合成ダメージ・効果を適用する。反射・反撃・従者破壊は同じ合成技に対して処理し、該当する破壊条件は和集合。近距離/陣営等の禁止は対象拡張後も維持する。合成元の「本技」は合成技全体を指す。矛盾する追加効果は使用宣言時に選んだ合法な専用効果で置き換え、それでも相互両立不能な組合せは宣言不可とする。取消で両カードを返さず、使い終われば各物理札を捨て札へ置く。持ち技回収等はG11に従って人物・正規化名称ごとの残回数と各物理札の使用事実を確認し、合成したことだけで2枚を一括回収しない。

### T11 — 竜王爆砕剣 / Q1

**対応**：`a2-p09-r2c2` Q1

**元の疑問**：追加間合い用1d6・3倍化抵抗用2d6を複数対象で共有するか個別に振るか。3倍化チェックと「次の手番を行なえず」の解決時機、手番スキップに回復フェイズを含むか。

**原文で確定**：ガイナス専用は追加1d6枚の間合い、命中した者は次の自分の手番を行えず、2d6で6以下を出さないと3倍ダメージ。 [CardAll 9ページ](../../../resources/original/second-edition/CardAll.pdf#page=9)。

**オンライン補完・暫定採用**：追加間合いの1d6は攻撃側の乱数として防御前に1回振り、全対象・全発で共有する。対象の3倍化抵抗2d6は命中後、通常ダメージ前に対象ごと1回振り、6以下なら通常、7以上ならその対象への命中分を3倍にする。各対象の次の手番スキップは命中時に付与する。スキップは回復・ドロー・行動・手札調整を含む手番全体を飛ばすが、席の手番が経過したという期間進行は記録する。同じ技グループの複数命中でスキップ回数を増やさず、別発動による次手番スキップも次の同じ手番1回に重ねる。

**対応**：`a2-p09-r3c1` Q1

**元の疑問**：即死要求の締切と、通常ダメージ・回復の割り込みとの順序を定める。

### T13 — 天地百撃斬 / Q1

**対応**：`a2-p10-r1c3` Q1

**元の疑問**：複数対象化時、発数1d6は技全体で共通か対象ごとか。非シンの事前精神力−2チェック失敗時のカード消費と使用取消の窓を定める。

### T14 — 天地爆砕剣 / Q1
